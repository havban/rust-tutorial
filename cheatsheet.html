Default integer is i32. No implicit conversions: use as (lossy) or try_into() (checked). Overflow panics in debug, wraps in release — say what you mean with checked_, saturating_, wrapping_.

Control flow

// if is an expression; condition must be bool
let s = if n > 5 { "big" } else { "small" };

loop { break value; }     // breaks with a value
while cond { }
for i in 0..5 { }          // 0..=5 includes 5
for x in &v { }           // borrow
for x in &mut v { }       // borrow mutably
for x in v { }            // consume

'outer: for a in .. { break 'outer; }

Functions

fn add(a: i32, b: i32) -> i32 {
    a + b        // no semicolon = return value
}
fn early(x: i32) -> i32 {
    if x < 0 { return 0; }  // leave early
    x
}

A semicolon discards a value. Missing -> means the function returns (); a stray semicolon on the last line is why you get expected i32, found ().

Ownership & borrowing

  1. Every value has exactly one owner.
  2. Dropped when the owner leaves scope.
  3. Many &T or one &mut T — never both.
  4. A reference may not outlive its referent.
let s2 = s1;        // MOVE: s1 unusable after
let s2 = s1.clone(); // deep copy, explicit cost
let r  = &s1;       // borrow: s1 still owner
let m  = &mut s1;   // exclusive borrow
TakeWhen
&Tyou only read — the default
&mut Tyou modify in place
Tyou store or consume it

Copy types (ints, floats, bool, char, &T, tuples of these) copy instead of moving. Borrows end at last use, not at the brace.

Pattern matching

match value {
    1          => ..,       // literal
    2 | 3      => ..,       // alternatives
    4..=9      => ..,       // range
    n if n < 0 => ..,       // guard
    n @ 1..=5  => ..,       // bind + test
    Point { x, .. } => ..,  // destructure
    [a, .., z] => ..,       // slice
    _          => ..,       // catch-all
}

if let Some(n) = opt { .. } else { .. }
while let Some(x) = stack.pop() { .. }
let Some(n) = opt else { return; }; // diverges
matches!(v, Some(n) if n > 2)        // -> bool

match is exhaustive: add an enum variant and every incomplete match becomes a compile error. That is the refactoring superpower — be sparing with _.

No integer indexing — strings are UTF-8, so s[0] would be meaningless. Slice by byte range (&s[0..5], panics off a char boundary) or use .chars(). Take &str in parameters.

use std::collections::HashMap;
let mut m = HashMap::new();
m.insert(k, val);  m.get(&k);  m.remove(&k);
*m.entry(k).or_insert(0) += 1;       // count

HashMap iteration order is deliberately random. Need order? BTreeMap. Membership only? HashSet / BTreeSet.

Error handling

enum Option<T> { Some(T), None }     // no null
enum Result<T, E> { Ok(T), Err(E) } // no throw

let n = text.parse::<i32>()?;   // propagate
// ? == "unwrap, or return Err(e.into())"

.unwrap_or(d) / .unwrap_or_else(..)
.unwrap_or_default() / .ok()
.map(..) / .map_err(..) / .and_then(..)
.ok_or(e) / .ok_or_else(..)  // Option -> Result
.expect("why I expected this")  // panics

Never Err(String) in a public API — callers end up matching on prose. expect over unwrap, always: the message is a comment the panic prints for you.

Implement From, never Into — you get Into free, plus the conversion ? uses. Orphan rule: you must own the trait or the type; otherwise wrap it in a newtype.

// Fn: reads · FnMut: mutates · FnOnce: consumes

Adapters are lazy — nothing runs until a consumer does. Chains fuse into one loop, so they cost no more than the handwritten version. Delete any collect() in the middle of a chain.

Smart pointers

Box<T>heap, one owner; recursive types
Rc<T>many owners, 1 thread
Arc<T>many owners, many threads
RefCell<T>borrow check at runtime
Mutex<T>one writer, many threads
RwLock<T>many readers / one writer
Cow<'a, T>borrow, clone only if needed

Rc<RefCell<T>> = shared mutable, single thread. Arc<Mutex<T>> = the same across threads. Cycles leak — break them with Weak<T>. Reaching for these everywhere usually means a Vec plus indices was the better design.

Concurrency

let h = thread::spawn(move || { .. });
h.join().unwrap();

// scoped threads may borrow locals
thread::scope(|s| { s.spawn(|| ..); });

let (tx, rx) = mpsc::channel();
tx.send(v)?;  for msg in rx { .. } // drop(tx)!

let c = Arc::new(Mutex::new(0));
*c.lock().unwrap() += 1;  // unlocks on drop

async fn f() -> T { g().await }
tokio::join!(a(), b())   // truly concurrent

Send = movable between threads. Sync = shareable by reference. Both inferred; Rc and RefCell are neither, which is why misuse is a compile error. Never block inside async.

Idioms worth internalising

  • Take &str, &[T], &Path — never &String, &Vec<T>, &PathBuf.
  • as_ free · to_ allocates · into_ consumes. try_ = fallible.
  • Newtype over bare primitives; enums over boolean parameters.
  • Make illegal states unrepresentable — then you cannot test for them because they cannot exist.
  • Parse, don't validate: return a type that proves the check ran.
  • #[must_use], #[non_exhaustive], and Debug on every public type.
  • Read the compiler error. It names the binding and usually prints the fix.
  • Read clippy. It is a free senior reviewer.
  • Reaching for clone() to silence the borrow checker means the ownership design is unclear.
  • Benchmarking a debug build is the most common performance mistake there is.
